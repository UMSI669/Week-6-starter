# SOULSBUILD

My app of choice will be called, *SoulsBuild*, a **React** **Native** application designed to help you discover, build and customize builds for your favorite RPG games.

The application will display character builds as interactive cards containing information such as game title, character attributes, weapons, equipment, and combat playstyle. As of now, sers will be able to search and filter builds based on specific preferences from Elden Ring including Strength, Dexterity, Intelligence, and Faith. Further developement will incorporate build stats from other games aswell.

### <ins>State management</ins>
- Zustand: manages user created data, including saved builds and customizations.

- TanStack Query: manages external API requests, caching, loading states, and error handling.

###Run
- npm install
- npx expo start
